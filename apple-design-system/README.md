# Apple Design System Skill

A design-oriented skill for building and auditing UIs that follow Apple's aesthetic of "Minimalism and Sophistication".

## Installation

This skill is part of the Antigravity skill library. It is automatically available once the files are in the `skills/apple-design-system` directory.

## Usage

Trigger this skill when you want to:

- "Design a website in Apple style"
- "Audit my UI for premium Apple-like feel"
- "Apply Apple's typography hierarchy"

## Features

- Core principles (Whitespace, Content-first, High-res imagery).
- Typography scales for headers and body.
- Interaction patterns (Pill buttons, Translucent navs).
- CSS examples for common Apple UI effects.

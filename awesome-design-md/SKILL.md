# Awesome DESIGN.md Skill

- When you need to read a `DESIGN.md` from the `awesome-design-md` repository to apply its design tokens.

## How to Use
1. **Identify the requested style:** Determine which design system the user wants (e.g., Stripe).
2. **Read the DESIGN.md:** Use `view_file` on the corresponding file, for example: `d:\Awesome Design MD\awesome-design-md\design-md\stripe\DESIGN.md`.
3. **Apply the styles:** Use the rules from the retrieved `DESIGN.md` (colors, typography, component stylings, depth, etc.) when writing CSS/Tailwind, components, or prompting other agents.
4. **Copy to project (Optional):** If requested, copy the `DESIGN.md` file into the root of the user's current project for future reference by other agents.
